# Цена Севера 🏠

Мобильная игра-угадайка: посмотрели на фотографии квартиры из **реальных объявлений Авито в Республике Коми** (г. Инта) — попробовали угадать цену бегунком. 10 квартир за игру, до 10 баллов за каждую.

Игра построена на дизайн-системе НИУ ВШЭ (фирменный синий `#012D6E`). Учебный проект.

## Как играть

1. Смотрите фотографии квартиры — листайте галерею свайпом.
2. Двигаете бегунок и жмёте «Оценить».
3. Видите реальную цену, переплату и ссылку на настоящее объявление.

## Балльная система

Ошибка считается относительно реальной цены: `|оценка − факт| / факт`.

| Ошибка | Баллы |
|--------|-------|
| ≤ 5%   | 10    |
| ≤ 10%  | 8     |
| ≤ 20%  | 6     |
| ≤ 30%  | 4     |
| ≤ 50%  | 2     |
| > 50%  | 0     |

Максимум за игру — **100 баллов**.

## Итоговые амплуа

По среднему отклонению ваших оценок от реальных цен (знак учитывается):

- **Жадный студент** — систематически называете *меньше* факта (средний сдвиг ≤ −10%)
- **Адекватный квартирант** — оценки совпадают с рынком (±10%)
- **Транжира** — систематически называете *больше* факта (сдвиг ≥ +10%)

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в репозиторий (например, `komi-price-game`).
2. **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.**
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/komi-price-game/`.

Файл `.nojekyll` уже включён — Jekyll-сборка не нужна, сайт статический (чистые HTML/CSS/JS, без зависимостей и сборки).

## Структура

```
index.html        — единственная страница, 4 экрана: старт → лот → результат → итоги
css/style.css     — стили в духе НИУ ВШЭ (#012D6E), mobile-first
js/app.js         — игровая логика (галерея, бегунок, баллы, амплуа, рекорд)
js/data.js        — 36 лотов: фото, цены, ссылки на Авито (сгенерирован)
img/              — оптимизированные фото (~900px, JPEG q72; всего ~1,3 МБ)
data/source.csv   — исходная выгрузка объявлений
.nojekyll         — для GitHub Pages
```

## Обновление данных

Данные генерируются скриптом PowerShell (нужен только Windows PowerShell + интернет):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File _build/build.ps1
```

Скрипт читает CSV-выгрузку объявлений, скачивает фотографии, сжимает их (максимум 900px по длинной стороне, JPEG качество 72) и пересобирает `js/data.js`. Лоты без фотографий в игру не попадают.

## Технические детали

- Mobile-first: одна карточка на экран, крупные тач-зоны, `viewport-fit=cover`, безопасные отступы iOS.
- Галерея — нативный scroll-snap, ленивая загрузка фото (первое — приоритетное).
- Бегунок зафиксирован в диапазоне 50 тыс. — 2 млн ₽ для всех лотов: границы подсказки не выдают.
- Цена за м² в игре не показывается — она напрямую выдаёт ответ.
- Лучший результат хранится в `localStorage`.
- Никаких фреймворков и внешних запросов в рантайме — быстро открывается и работает офлайн после первой загрузки.
